# Card 21 Game (Blackjack-style)

## Description
Card 21 is a simplified blackjack-style GUI game where the player aims to reach 21 without going over, competing against a computer-controlled dealer.

## Features
- Main Menu: New Game, Help/Instructions, Exit
- Game Screen: Player hand, Dealer hand, Hit / Stand / New Round buttons
- Status/Score area and win/lose/tie messages
- Help screen explaining rules and controls

## Requirements
- Python 3 (if your project is in Python)
- GUI dependencies used by the project (e.g., PyQt5) if applicable

## Installation
1. Download/clone this repository.
2. Open the project in your IDE (or a terminal).
3. Install any required dependencies (if needed).

## Usage
- Run the main file (e.g., `main.py`) to start the game.
- Click **Hit** to draw a card, **Stand** to end your turn, and **New Round** to play again.
- Read **Help** for the rules and how controls work.

## Known Limitations
- Scores are not saved between sessions.
- Animations may be minimal.
- No sound effects.
